# Biohub Cell Tracking During Development

Overview
 
This repository contains my work for the Kaggle Biohub – Cell Tracking During Development competition. It also serves as my semester-long deep learning project, documenting my progress as I learn 3D computer vision, biomedical image analysis, and research-oriented model development.


## Objectives

* Strengthen PyTorch and learn deep learning model training
* Understand 3D biomedical image analysis
* Explore object detection and multi-object tracking
* Build an end-to-end machine learning pipeline
* Document experiments, results, and lessons learned



## Repository Structure

```text
docs/            Competition notes, references, and learning resources
experiments/     Experiment logs and observations
kaggle-notebooks/ Kaggle notebooks used for training and exploration
papers/          Research papers and useful references
src/             Reusable Python code (added as the project develops)
```
